# Aby

A Codex custom pet based on a show-grade Abyssinian cat:

- Long, lean athletic body
- Ruddy cinnamon-brown ticked coat
- Large alert ears and green almond eyes
- Close-to-realistic sprite style

## Preview

![Aby contact sheet](contact-sheet.png)

## Files

- `pet.json`: Codex pet manifest
- `spritesheet.webp`: animated pet spritesheet
- `contact-sheet.png`: preview of all animation rows

## Install

Copy this folder to your local Codex pets directory:

```bash
mkdir -p ~/.codex/pets
cp -R pets/aby ~/.codex/pets/
```
