# Cat Quartet

A Codex custom pet featuring four cats together:

- Tuxedo cat
- Ragdoll cat
- Abyssinian cat
- Siamese cat

## Preview

![Cat Quartet contact sheet](contact-sheet.png)

## Files

- `pet.json`: Codex pet manifest
- `spritesheet.webp`: animated pet spritesheet
- `contact-sheet.png`: preview of all animation rows

## Install

Copy this folder to your local Codex pets directory:

```bash
mkdir -p ~/.codex/pets
cp -R pets/cat-quartet ~/.codex/pets/
```
